# 🛒 E‑Commerce Product Service

## 📌 Overview
This demo service provides core e‑commerce features including:

- **Product Listing** – Browse available products in the catalog.  
- **Advanced Search** – Perform keyword and full‑text searches.  
- **Dynamic Filtering** – Filter products by attributes (category, price, rating, etc.).  
- **Pagination Support** – Efficiently handle large datasets with paginated responses.  
- **Swagger UI** – Interactive API documentation for developers.  

---

## 🚀 Features
- RESTful API endpoints for product management.  
- Integrated search and filtering logic.  
- Pagination for scalable product listing.  
- Swagger UI for API exploration and testing.
